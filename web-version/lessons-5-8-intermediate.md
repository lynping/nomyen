# บทที่ 5: Prompt ขั้นกลาง — Role / Format / Few-shot 🌿

**เป้าหมาย:** ผู้เรียนยกระดับ prompt ด้วย 3 เทคนิคมืออาชีพ: กำหนดบทบาท, ล็อครูปแบบผลลัพธ์, สอนด้วยตัวอย่าง

## หัวข้อ 5.1 — กำหนดบทบาท (Role)

- เทคนิค: เริ่ม prompt ด้วย "คุณคือ..." เพื่อให้ AI สวมมุมมองผู้เชี่ยวชาญ
- ตัวอย่าง:
  - "คุณคือนักการตลาดที่เชี่ยวชาญตลาดคนวัย 40+" → คำตอบจะคิดแบบนักการตลาด
  - "คุณคือ HR ที่เข้มงวดเรื่องการคัดเรซูเม่ ช่วยติเรซูเม่นี้แบบตรงไปตรงมา"
  - "คุณคือติวเตอร์ใจดี อธิบายให้คนไม่มีพื้นฐานเข้าใจ"
- ทำไมเวิร์ค: บทบาทช่วยล็อค "มุมมอง + ระดับภาษา + เกณฑ์คุณภาพ" ในคำเดียว
- ทริคเสริม: กำหนดบทบาทให้ "ผู้อ่าน" ด้วยยิ่งดี — "เขียนให้เจ้าของกิจการเล็กๆ ที่ไม่มีเวลาอ่าน"

## หัวข้อ 5.2 — ล็อครูปแบบผลลัพธ์ (Output Format)

- สั่งรูปแบบได้ละเอียดกว่าที่คิด:
  - "ตอบเป็นตาราง 3 คอลัมน์: ปัญหา / สาเหตุ / วิธีแก้"
  - "ทำเป็น checklist ติ๊กได้"
  - "เขียนเป็นสคริปต์พูด ยาว 1 นาที"
  - "ตอบสั้นๆ ก่อน 1 บรรทัด แล้วค่อยอธิบายละเอียดข้างล่าง"
- เทคนิคโครงร่างบังคับ: ให้หัวข้อไปเลย เช่น "ตอบตามโครงนี้: 1) สรุป 2) ข้อดี 3) ข้อเสีย 4) คำแนะนำ"
- ประโยชน์จริง: ผลลัพธ์ copy ไปใช้ต่อได้ทันที ไม่ต้องจัดใหม่

## หัวข้อ 5.3 — สอนด้วยตัวอย่าง (Few-shot)

- แนวคิด: แทนที่จะอธิบายสไตล์ที่ต้องการยาวๆ → แปะตัวอย่าง 2-3 ชิ้นให้ดู แล้วบอก "ทำแบบนี้กับอันใหม่"
- ตัวอย่างใช้จริง:
  - แปะโพสต์เก่า 3 โพสต์ที่ยอดดี → "เขียนโพสต์ใหม่เรื่อง X ในสไตล์เดียวกัน"
  - แปะอีเมลที่เราเขียนเอง 2 ฉบับ → "ต่อไปเขียนอีเมลด้วยน้ำเสียงแบบฉัน"
  - แปะตัวอย่างการตั้งชื่อไฟล์/รหัสสินค้า → ให้ตั้งต่อตามแพทเทิร์น
- นี่คือเทคนิคที่ทำให้ AI "เขียนเหมือนเรา" ได้จริง
- **Checkpoint:** ให้ผู้เรียนเลือกงานเขียนที่มีสไตล์เฉพาะของตัวเอง แล้วลอง few-shot

## หัวข้อ 5.4 — ประกอบร่าง 3 เทคนิค

โชว์ prompt ที่ใช้ครบทุกอย่าง (role + งาน + บริบท + format + few-shot) จากงานจริงของผู้เรียน แล้วเทียบผลกับ prompt สั้นๆ ให้เห็นความต่างจะจะ

## 🏋️ แบบฝึกหัดท้ายบท (ชิ้นส่วนโปรเจกต์ #5)

1. อัปเกรด prompt หลักของโปรเจกต์ (จากบทที่ 3) ด้วย role + format ที่เหมาะ
2. เพิ่มตัวอย่างผลงานจริงของผู้เรียน 2-3 ชิ้นเป็น few-shot
3. เทียบผลก่อน/หลังอัปเกรด เล่าให้นมเย็นฟัง
4. บันทึกเวอร์ชันใหม่ลง `my-project/prompts.md` (ติดป้าย v2)

## สรุปท้ายบท

Role ล็อคมุมมอง / Format ล็อคหน้าตา / Few-shot ล็อคสไตล์ / ใช้ร่วมกันคือ prompt ระดับมืออาชีพ / บทต่อไป: เอาทั้งหมดไปถล่มงานออฟฟิศจริง
# บทที่ 6: งานออฟฟิศจริง — อีเมล สรุปประชุม รายงาน 🌿

**เป้าหมาย:** ผู้เรียนใช้ AI ทำงานประจำวันได้จริงอย่างน้อย 3 ประเภท และเริ่มมี template ของตัวเอง

> หมายเหตุถึงนมเย็น: บทนี้ให้เลือกเน้นหัวข้อที่ตรงกับอาชีพผู้เรียนมากที่สุด ไม่ต้องสอนครบทุกหัวข้อเท่ากัน

## หัวข้อ 6.1 — งานอีเมล/ข้อความ

- เขียนใหม่: อีเมลตามงาน, ขอบคุณลูกค้า, ปฏิเสธแบบรักษาน้ำใจ, นัดหมาย, ทวงเงินแบบสุภาพ
- ปรับของเดิม: "ทำให้สุภาพขึ้น", "สั้นลงครึ่งหนึ่ง", "เปลี่ยนเป็นภาษาอังกฤษแบบ business"
- ตอบอีเมลยาก: แปะอีเมลที่ได้รับ → "ช่วยร่างคำตอบ ที่ยืนยันจุดยืนเราแต่ไม่เสียความสัมพันธ์"
- เคล็ดลับ: สร้าง "อีเมลสูตรสำเร็จ" — prompt เดียวที่มีน้ำเสียงเรา + ลายเซ็น + โครงที่ใช้ประจำ

## หัวข้อ 6.2 — สรุปประชุม

- จากโน้ตย่อ → รายงานประชุมเต็ม: พิมพ์โน้ตสั้นๆ ระหว่างประชุม แล้วให้ AI ขยายเป็นสรุปเป็นทางการ
- โครงมาตรฐานที่ควรสั่ง: ผู้เข้าประชุม / เรื่องที่คุย / มติ / action items (ใครทำอะไร เมื่อไหร่)
- จากไฟล์เสียงถอดความ (ถ้ามี) → "สรุปเฉพาะการตัดสินใจและงานที่มอบหมาย"
- ทริค: "อ่านสรุปนี้แล้วมีอะไรที่ประชุมน่าจะลืมคุย/ตกหล่นไหม" — AI ช่วยเช็คความครบ

## หัวข้อ 6.3 — รายงานและเอกสารเป็นทางการ

- โครงก่อน เนื้อทีหลัง: ให้ AI เสนอโครงรายงานก่อน → เราปรับโครง → ค่อยให้เขียนทีละส่วน (งานยาวได้คุณภาพกว่าสั่งรวดเดียว)
- แปลงข้อมูลดิบเป็นรายงาน: แปะตัวเลข/ข้อมูล → "เขียนบทวิเคราะห์สำหรับผู้บริหาร พร้อมข้อเสนอแนะ"
- ตรวจงาน: "ตรวจเอกสารนี้ หาคำผิด ประโยควกวน และจุดที่อ่านแล้วสับสน"

## หัวข้อ 6.4 — สร้าง Template ประจำตัว

- แนวคิด: งานไหนทำซ้ำทุกสัปดาห์ → ทำเป็น template: prompt สำเร็จรูปที่เว้นช่องว่างไว้เติม
- ตัวอย่าง template:

> "คุณคือเลขาที่เขียนสรุปประชุมเก่งมาก สรุปโน้ตต่อไปนี้เป็นรายงานประชุมภาษาไทยทางการ โครง: เรื่องที่คุย / มติ / action items เป็นตาราง (ใคร-ทำอะไร-กำหนดเสร็จ) โน้ต: [แปะโน้ตตรงนี้]"

- ใช้งาน: copy template → เติมช่องว่าง → ส่ง — งานที่เคยใช้ 30 นาทีเหลือ 3 นาที

## 🏋️ แบบฝึกหัดท้ายบท (ชิ้นส่วนโปรเจกต์ #6)

1. เลือกงานประจำที่ทำบ่อยที่สุด 2 อย่าง → สร้างเป็น template ตามหัวข้อ 6.4
2. ทดลองใช้กับงานจริงอย่างน้อย 1 ครั้ง
3. บันทึกลงไฟล์ใหม่ `my-project/templates.md` — ตอนนี้โปรเจกต์เริ่มเป็นรูปเป็นร่างแล้ว!

## สรุปท้ายบท

AI ทำงานออฟฟิศแทนได้เกินครึ่ง ถ้าเราสั่งเป็น / งานซ้ำๆ = ทำ template / โครงก่อนเนื้อทีหลังสำหรับงานยาว / บทต่อไป: ทำให้ AI "จำเราได้" ไม่ต้องเล่าใหม่ทุกครั้ง
# บทที่ 7: Projects, Custom Instructions, Memory, GPTs 🌿

**เป้าหมาย:** ผู้เรียนตั้งค่าให้ AI "รู้จักเรา" ถาวร ไม่ต้องเล่าบริบทใหม่ทุกครั้ง และสร้างพื้นที่ทำงานเฉพาะเรื่อง

## หัวข้อ 7.1 — ปัญหาที่บทนี้แก้

- ทุกบทที่ผ่านมา เราต้องเล่าบริบท + แปะตัวอย่างทุกครั้งที่เปิดแชทใหม่ → เหนื่อย
- เครื่องมือในบทนี้ = "ตั้งค่าครั้งเดียว ใช้ได้ตลอด" — จุดเปลี่ยนจากผู้ใช้ทั่วไปเป็น power user

## หัวข้อ 7.2 — Custom Instructions / ตั้งค่าส่วนตัว

- ทั้ง Claude และ ChatGPT มีที่ให้เขียน "ข้อมูลเกี่ยวกับฉัน + อยากให้ตอบยังไง" ในหน้า Settings (ชื่อเมนูอาจต่างกัน ให้หาคำว่า personalization / custom instructions / profile)
- สิ่งที่ควรใส่:
  - เราเป็นใคร ทำงานอะไร (เช่น "เจ้าของร้านค้าออนไลน์ ขายเสื้อผ้า")
  - ชอบให้ตอบแบบไหน (เช่น "ตอบภาษาไทย กระชับ เป็นข้อๆ ไม่ต้องเกริ่นยาว")
- ผล: ทุกแชทใหม่ AI จะรู้จักเราทันที
- ให้ผู้เรียนเขียนของตัวเองจริงๆ ในคาบนี้ (นมเย็นช่วยร่าง)

## หัวข้อ 7.3 — Projects (Claude) / Projects (ChatGPT)

- Project = โฟลเดอร์รวมแชทเรื่องเดียวกัน + ใส่ "คำสั่งประจำ" + แนบไฟล์ความรู้ถาวรได้
- ตัวอย่างการใช้:
  - Project "ร้านของฉัน" — แนบรายการสินค้า+ราคา+นโยบายร้าน / คำสั่งประจำ: สไตล์การตอบลูกค้า → ทุกแชทใน project ตอบเรื่องร้านได้เลย
  - Project "รายงานประจำเดือน" — แนบ template รายงาน + ตัวอย่างเดือนก่อน
- นี่คือบ้านถาวรของ template ที่เราสร้างในบทที่ 6!
- **Checkpoint:** ให้ผู้เรียนสร้าง project แรกสำหรับโปรเจกต์ประจำตัวของเขา

## หัวข้อ 7.4 — Memory (ความจำระยะยาว)

- AI บางตัวมีระบบ "จำข้อมูลข้ามแชท" อัตโนมัติ (เปิด/ปิดได้ใน settings)
- ข้อดี: สะดวก ไม่ต้องเล่าซ้ำ / ข้อควรระวัง: อาจจำเรื่องที่เราไม่อยากให้จำ — ลบได้ ตรวจสอบได้ในหน้า settings
- แนะนำ: รู้ว่ามันมีอยู่ รู้วิธีดู/ลบ แล้วเลือกเองว่าจะเปิดไหม

## หัวข้อ 7.5 — Custom GPTs (ฝั่ง ChatGPT)

- GPTs = แชทบอทสำเร็จรูปที่คนอื่นสร้างไว้ (มี store ให้เลือก) หรือเราสร้างเองได้โดยไม่ต้องเขียนโค้ด
- แนวคิดเดียวกับ Projects: ยัดคำสั่ง + ความรู้ + ตัวอย่างเข้าไปถาวร
- เหมาะเมื่อ: อยากแชร์ผู้ช่วยให้คนอื่นในทีมใช้ด้วย

## 🏋️ แบบฝึกหัดท้ายบท (ชิ้นส่วนโปรเจกต์ #7 — ชิ้นใหญ่!)

1. เขียน Custom Instructions ของตัวเองและบันทึกใช้จริง
2. สร้าง Project สำหรับโปรเจกต์ประจำตัว: ใส่คำสั่งประจำ (จาก prompts.md + templates.md) และแนบไฟล์ที่เกี่ยวข้อง
3. ทดสอบ: เปิดแชทใหม่ใน project แล้วสั่งงานสั้นๆ ดูว่า AI เข้าใจบริบทเราทันทีไหม
4. บันทึกสิ่งที่ตั้งค่าลง `my-project/setup.md` (กันลืม + เผื่อย้ายไปใช้เครื่องมืออื่น)

## สรุปท้ายบท

ตั้งค่าครั้งเดียวใช้ตลอด / Custom Instructions = AI รู้จักเรา / Projects = บ้านของงานแต่ละเรื่อง / โปรเจกต์ประจำตัวตอนนี้มีบ้านจริงแล้ว! / บทต่อไป: งานสร้างสรรค์และวิเคราะห์ข้อมูล
# บทที่ 8: งานสร้างสรรค์ + วิเคราะห์ข้อมูล 🌿

**เป้าหมาย:** ผู้เรียนใช้ AI เป็นคู่คิดระดมไอเดีย และวิเคราะห์ข้อมูล/ตัวเลขเบื้องต้นได้

## หัวข้อ 8.1 — AI เป็นคู่คิด ไม่ใช่แค่คนรับคำสั่ง

- เปลี่ยนโหมดจาก "สั่งงาน" เป็น "ชวนคิด":
  - "ขอไอเดีย 10 แบบ เอาแปลกๆ บ้าง" → แล้วค่อยคัดพัฒนาต่อ
  - "ช่วยแย้งไอเดียนี้หน่อย มีจุดอ่อนตรงไหน" — ให้ AI เป็นกระจกสะท้อน
  - "ถ้าคู่แข่งจะชนะเรา เขาจะทำอะไร" — เปลี่ยนมุมคิด
- เทคนิคระดมไอเดียคุณภาพ: ขอปริมาณก่อน (20 ไอเดียแย่ๆ ดีกว่า 3 ไอเดียกลางๆ) แล้วสั่ง "เอาข้อ 4 กับ 11 มารวมกันแล้วพัฒนาต่อ"

## หัวข้อ 8.2 — งานคอนเทนต์และงานเขียนสร้างสรรค์

- ครบวงจร: คิดหัวข้อ → ทำโครง → เขียนร่าง → ปรับสไตล์ → ทำหลายเวอร์ชันสำหรับหลายแพลตฟอร์ม
- ทริคเด็ด "1 เนื้อหา หลายร่าง": เขียนบทความ 1 ชิ้น → "แปลงเป็นโพสต์ Facebook / caption IG / สคริปต์วิดีโอสั้น"
- รักษาความเป็นตัวเอง: ใช้ few-shot จากบทที่ 5 เสมอ — งานสร้างสรรค์ที่ไม่มีตัวอย่างจะได้กลิ่น "AI เขียน" ชัด
- จริยธรรมสั้นๆ: งานที่เผยแพร่ควรผ่านการอ่าน/ปรับของเราเสมอ — AI ช่วยร่าง เราเป็นเจ้าของ

## หัวข้อ 8.3 — วิเคราะห์ข้อมูลเบื้องต้น

- แปะข้อมูล (ตาราง, ยอดขาย, ผลสำรวจ) หรือแนบไฟล์ Excel/CSV แล้วสั่ง:
  - "สรุปแนวโน้มสำคัญ 3 อย่างจากข้อมูลนี้"
  - "เดือนไหนขายดีสุด/แย่สุด เพราะอะไรได้บ้าง"
  - "มีอะไรผิดปกติในข้อมูลนี้ไหม"
- ขอภาพ: AI สร้างกราฟ/chart ได้ (Claude ทำ artifacts, ChatGPT ทำกราฟจากไฟล์) — "ทำกราฟแท่งเทียบยอดขายรายเดือน"
- ข้อควรระวังพิเศษ: **การคำนวณตัวเลขต้องตรวจทานเสมอ** — AI อาจบวกเลขผิดหน้าตาย ถ้าตัวเลขสำคัญให้เช็คกับ Excel

## หัวข้อ 8.4 — ค้นเว็บและข้อมูลสด

- AI รุ่นใหม่ค้นเว็บได้ (web search) — ใช้เมื่อต้องการข้อมูลล่าสุด เช่น ราคา, ข่าว, เทรนด์
- สั่งชัดๆ: "ช่วยค้นข้อมูลล่าสุดเรื่อง..." และขอแหล่งอ้างอิงเสมอ: "ใส่ลิงก์ที่มาด้วย"
- นิสัยดี: คลิกเช็คแหล่งจริงก่อนเอาไปใช้ต่อ
