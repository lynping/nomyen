# 🧋 นมเย็น — คอร์สเรียนใช้ AI ตั้งแต่ศูนย์จนโปร

คอร์สสอนใช้งาน AI (Claude และ ChatGPT) 13 บท โดยมี **"นมเย็น"** ครู AI ส่วนตัวที่สอนแบบเป็นกันเอง ปรับเนื้อหาตามอาชีพของคุณ จำความคืบหน้าได้ (หยุดเมื่อไหร่ก็ได้ กลับมาเรียนต่อได้เสมอ) และเรียนจบพร้อม**โปรเจกต์จริงของตัวเอง 1 ชิ้น**

## 🚀 วิธีเริ่มเรียน

1. เปิดโฟลเดอร์นี้ใน **Claude Code**
2. พิมพ์อะไรก็ได้ เช่น "สวัสดี"
3. นมเย็นจะทักทาย ถามข้อมูล แล้วพาเริ่มบทที่ 1 — แค่นั้นเลย

กลับมาเรียนต่อ: เปิดโฟลเดอร์เดิม พิมพ์ "เรียนต่อ" นมเย็นจำได้ว่าค้างตรงไหน

## 🎒 สิ่งที่ต้องเตรียม

| สิ่งที่ต้องมี | ใช้ตอนไหน | หมายเหตุ |
|---|---|---|
| คอมพิวเตอร์ + อินเทอร์เน็ต | ตลอดคอร์ส | |
| บัญชี Claude (claude.ai) หรือ ChatGPT (chatgpt.com) | บท 1-9 | สมัครฟรี |
| Claude Code | บท 10-13 + ตัวคอร์สนี้ | ปกติต้องมีแพ็กเกจเสียเงิน (ดูหัวข้อถัดไป) |
| ไฟล์งานจริง 2-3 ชิ้น (เอกสาร/รูป/ตาราง) | แบบฝึกหัดบท 4, 6, 8 | ใช้ของจริงสนุกกว่าโจทย์สมมติ |

**ไม่ต้องมี:** พื้นฐานเขียนโปรแกรม, ความรู้ AI มาก่อน — บท 1 เริ่มจากศูนย์จริงๆ

## 💰 บทไหนฟรี บทไหนต้องเสียเงิน

- **บท 1-9 (70% ของคอร์ส):** ใช้บัญชี **ฟรี** ได้ครบ — ข้อจำกัดเดียวคือโควต้าใช้งานต่อวัน ถ้าเต็มก็พักแล้วมาเรียนต่อ
- **บท 10-13 (ภาค Claude Code):** Claude Code ปกติต้องใช้แพ็กเกจเสียเงิน (Pro ขึ้นไป) หรือเครดิต API — เงื่อนไขและราคาเปลี่ยนได้ เช็คล่าสุดที่ claude.com

## 🆓 ใช้แบบฟรีอยู่? เรียนได้ 3 ทาง

1. **เรียนผ่านเว็บแทน (แนะนำ)** — เอานมเย็นไปสิงใน Project บน claude.ai หรือ Custom GPT: ดูวิธีติดตั้งใน [web-version/nomyen-web.md](web-version/nomyen-web.md) — เรียนได้ครบทุกบท (บท 10-13 ปรับเป็นภาคทฤษฎี + ทางเลือกฟรี)
2. **เรียน 1-9 ให้จบก่อน** — ได้ของใช้จริงเต็มๆ โดยไม่จ่ายสักบาท ถึงบท 10 ค่อยตัดสินใจว่าคุ้มอัปเกรดไหม
3. **เรียนบท 10-13 แบบทฤษฎี** — เข้าใจแนวคิด Claude Code / Skill / MCP แล้วทำโปรเจกต์จบด้วยเครื่องมือฟรี (Project + prompt chain + template) — นมเย็นจะปรับเส้นทางให้อัตโนมัติถ้าบอกว่าใช้แบบฟรี

## 🔄 เนื้อหาทันสมัยตลอดเวลา

โลก AI เปลี่ยนเร็ว คอร์สนี้เลยออกแบบ 2 ชั้น: ไฟล์บทเรียนสอน**หลักการ**ที่ไม่ค่อยเปลี่ยน ส่วน**ข้อเท็จจริงรายวัน** (ฟีเจอร์ ราคา เมนู) นมเย็นจะค้นเว็บเช็คของจริงก่อนสอนบทที่เปลี่ยนบ่อย — เจออะไรล้าสมัยในไฟล์ นมเย็นแก้ให้เองระหว่างสอน
