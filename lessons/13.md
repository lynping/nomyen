# บทที่ 13: โปรเจกต์จบ — ประกอบร่าง + รีวิว 🌳🎓

**เป้าหมาย:** ประกอบผลงานทั้งหมดใน `my-project/` เป็นโปรเจกต์สมบูรณ์ที่ใช้งานได้จริง ผ่านการรีวิวจากนมเย็น และผู้เรียนจบคอร์สพร้อมแผนเรียนรู้ต่อ

> หมายเหตุถึงนมเย็น: บทนี้ไม่มีเนื้อหาใหม่ — เป็นบทลงมือทำล้วนๆ บทบาทของเราคือโค้ช+กรรมการ ให้ผู้เรียนเป็นคนทำเองมากที่สุด

## ขั้นที่ 1 — ตรวจนับคลังแสง

เปิด `my-project/` ทบทวนด้วยกันว่ามีอะไรแล้วบ้าง:

- `ideas.md` — ไอเดียและแผน (บท 1, 8)
- `prompts.md` — คลัง prompt (บท 2, 3, 4, 5)
- `templates.md` — template งานประจำ (บท 6)
- `setup.md` — Custom Instructions + Project ที่ตั้งค่าไว้ (บท 7)
- `workflow.md` — prompt chain ของงานหลัก (บท 9)
- `my-claude-md.md` — CLAUDE.md ของตัวเอง (บท 11)
- `my-skill/` — Skill ที่สร้างเอง (บท 12)

ถ้าชิ้นไหนขาด/อ่อน ให้กลับไปเติมก่อน (นี่คือเหตุผลที่บทนี้ควรมีเวลาเหลือๆ)

## ขั้นที่ 2 — ประกอบเป็นโปรเจกต์สมบูรณ์

ให้ผู้เรียนสร้างไฟล์สุดท้าย `my-project/README.md` — "คู่มือใช้งานโปรเจกต์ของฉัน" ประกอบด้วย:

1. **ชื่อโปรเจกต์ + มันแก้ปัญหาอะไร** (2-3 ประโยค)
2. **วิธีใช้งานทีละขั้น** — ตั้งแต่เปิดเครื่องมือ จนได้ผลลัพธ์ (อ้างอิง prompt/template/workflow/skill ที่มี)
3. **เครื่องมือที่ใช้** — แชทตัวไหน, Project ไหน, Claude Code + skill ตรงไหน
4. **เวลาที่ประหยัดได้** — ประเมินคร่าวๆ เทียบก่อน/หลังใช้ AI

เคล็ดลับ: ให้ผู้เรียนลองใช้ AI ช่วยเขียน README นี้เอง — นี่แหละคือข้อสอบปลายภาคตัวจริง (เขาต้องสั่ง AI เป็นแล้ว!)

## ขั้นที่ 3 — ทดสอบของจริง

- ให้ผู้เรียนรันโปรเจกต์จริง 1 รอบเต็ม ตั้งแต่ต้นจนได้ผลลัพธ์สุดท้าย
- เจอจุดสะดุดตรงไหน → แก้ prompt/template/workflow/skill แล้วอัปเดตไฟล์

## ขั้นที่ 4 — นมเย็นรีวิว

รีวิวอย่างจริงใจและสร้างสรรค์ ตามเกณฑ์:

- ✅ ใช้งานได้จริงไหม — คนอื่นอ่าน README แล้วทำตามได้หรือเปล่า
- ✅ prompt มีครบองค์ประกอบไหม (สูตรบท 3+5)
- ✅ มีจุดตรวจสอบความถูกต้องไหม (บท 2: hallucination, บท 8: ตัวเลข)
- ✅ skill ถูกเรียกใช้ได้จริงไหม (บท 12)
- ✅ ประหยัดเวลาจริงไหม
- 💡 เสนอ 2-3 ไอเดียต่อยอด

จากนั้น **มอบประกาศนียบัตร**: เขียนไฟล์ `my-project/CERTIFICATE.md` — ใบประกาศจบหลักสูตรจากนมเย็น ระบุชื่อผู้เรียน วันที่ โปรเจกต์ที่ทำสำเร็จ และคำอวยพร ตกแต่งให้น่ารักสมฉายานมเย็น 🧋🎓

## ขั้นที่ 5 — เส้นทางต่อจากนี้

แนะนำตามความสนใจผู้เรียน:

- **สายลึก prompt:** ฝึกทำ chain ซับซ้อนขึ้น, ลองเทคนิคใหม่ๆ ที่เจอตามข่าวสาร AI
- **สายอัตโนมัติ:** ต่อยอด Claude Code — สร้าง skill เพิ่ม, ต่อ MCP กับเครื่องมือที่ใช้, ตั้งงานอัตโนมัติตามเวลา
- **สายแชร์:** สอนทีม/เพื่อนต่อ, แชร์ skill ให้ทีมใช้, ทำ GPT หรือ Project ให้ทีมใช้ร่วมกัน
- **แหล่งตามข่าว:** บล็อกของ Anthropic/OpenAI, คอมมูนิตี้ AI ไทย
- ย้ำส่งท้าย: AI เปลี่ยนเร็ว แต่หลักที่เรียนมา (บริบท, สูตร prompt, iterate, ตรวจสอบ, workflow, skill) ใช้ได้ตลอด
