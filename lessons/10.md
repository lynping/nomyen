# บทที่ 10: รู้จัก Claude Code 🌳

**เป้าหมาย:** ผู้เรียนเข้าใจว่า Claude Code คืออะไร ต่างจากแชทยังไง ติดตั้งและใช้งานพื้นฐานได้

> หมายเหตุถึงนมเย็น: ผู้เรียนกำลังเรียนอยู่ "ใน Claude Code" ตอนนี้เลย! ใช้จุดนี้สอนได้: "ที่คุยกับเราอยู่นี่แหละคือ Claude Code" — เป็นตัวอย่างที่จับต้องได้ที่สุด
>
> ⚠️ ก่อนเริ่มบทนี้ เช็คแพ็กเกจผู้เรียนจาก PROGRESS.md: Claude Code ปกติต้องใช้แพ็กเกจเสียเงิน ถ้าผู้เรียนใช้ฟรี (กรณีเรียนผ่านเวอร์ชันเว็บ) ให้บอกตรงๆ อย่างนุ่มนวล แล้วเสนอ 2 ทาง: (1) เรียนบท 10-11 เป็นภาคทฤษฎีให้เห็นภาพ ไว้มี Claude Code เมื่อไหร่ใช้ได้ทันที หรือ (2) ข้ามไปทำโปรเจกต์จบด้วยเครื่องมือฟรี — ให้ผู้เรียนเลือกเอง ห้ามกดดันให้จ่ายเงิน

## หัวข้อ 10.1 — Claude Code คืออะไร ต่างจากแชทยังไง

- แชท (claude.ai): เราคุย → AI ตอบเป็นข้อความ → เรา copy ไปใช้เอง
- Claude Code: AI อยู่ในเครื่องเรา **ลงมือทำเองได้จริง** — อ่านไฟล์, สร้างไฟล์, แก้ไฟล์, รันคำสั่ง, ทำงานหลายขั้นตอนต่อเนื่องจนจบ
- เปรียบเทียบ: แชท = ที่ปรึกษาปลายสาย / Claude Code = ผู้ช่วยที่นั่งอยู่หน้าคอมเราแล้วทำงานให้ดูต่อหน้า
- ชื่อมีคำว่า Code แต่**ไม่ได้มีไว้สำหรับโปรแกรมเมอร์เท่านั้น** — ใช้จัดการไฟล์เอกสาร, สรุปงาน, จัดระเบียบโฟลเดอร์, ทำงานอัตโนมัติได้หมด (คอร์สนี้ที่ผู้เรียนกำลังเรียนก็คือตัวอย่าง!)

## หัวข้อ 10.2 — ติดตั้งและเริ่มใช้

- มีหลายรูปแบบให้เลือก: แอป desktop (Mac/Windows), ใช้ผ่านเว็บ (claude.ai/code), พิมพ์คำสั่งใน terminal, หรือส่วนขยายใน IDE — แนะนำ**แอป desktop** สำหรับคนไม่ใช่สายเทคนิค (รูปแบบที่มีอาจเพิ่ม/เปลี่ยน ให้นมเย็นค้นเช็คล่าสุดก่อนสอน)
- ขั้นตอนหลัก: ติดตั้ง → ล็อกอินบัญชี Claude → เปิดโฟลเดอร์ที่จะทำงาน → พิมพ์สั่งได้เลย
- แนวคิดสำคัญ: Claude Code ทำงาน "ในโฟลเดอร์ที่เราเปิด" — เหมือนจ้างผู้ช่วยมาประจำที่โต๊ะทำงานตัวหนึ่ง
- รายละเอียดการติดตั้งอาจเปลี่ยน — ให้เช็คจาก claude.com/claude-code ประกอบ

## หัวข้อ 10.3 — งานแรกๆ ที่ควรลอง (ไม่ต้องเขียนโค้ดสักบรรทัด)

- "ดูไฟล์ในโฟลเดอร์นี้หน่อย มีอะไรบ้าง"
- "อ่านไฟล์ report.docx แล้วสรุปให้ฟัง"
- "สร้างไฟล์ checklist งานสัปดาห์นี้จากที่ฉันเล่า"
- "เปลี่ยนชื่อไฟล์รูปทั้งหมดในโฟลเดอร์นี้เป็น วันที่_ชื่องาน"
- "รวมไฟล์สรุปประชุม 4 ไฟล์นี้เป็นรายงานเดียว"
- จุดขาย: งานที่ต้องเปิด 10 ไฟล์ทำทีละอัน → สั่งประโยคเดียวจบ

## หัวข้อ 10.4 — ระบบความปลอดภัย (Permissions)

- Claude Code จะ**ขออนุญาตก่อนทำ**สิ่งที่กระทบไฟล์/ระบบ — เราเห็นทุกอย่างที่มันจะทำ กดอนุญาตหรือปฏิเสธได้
- กติกาที่ดีสำหรับมือใหม่: อ่านก่อนกดอนุญาตเสมอ, เริ่มจากโฟลเดอร์ทดลอง (ไม่ใช่โฟลเดอร์งานจริงทั้งก้อน), งานลบไฟล์ให้ระวังเป็นพิเศษ
- แนะนำให้รู้จัก backup: งานสำคัญควรมีสำเนาก่อนให้ AI จัดการ

## 🏋️ แบบฝึกหัดท้ายบท (ชิ้นส่วนโปรเจกต์ #10)

1. ติดตั้ง Claude Code (ถ้ายังไม่มี — มีแล้วข้ามได้เพราะกำลังใช้อยู่!)
2. สร้างโฟลเดอร์ทดลอง ใส่ไฟล์เอกสาร 2-3 ไฟล์ แล้วสั่งให้ Claude Code อ่าน+สรุป+สร้างไฟล์สรุปรวม
3. ลองสั่งงานที่เกี่ยวกับโปรเจกต์ประจำตัว 1 อย่าง เช่น ให้จัดระเบียบ `my-project/` หรือสร้างไฟล์ template เพิ่ม
4. เล่าประสบการณ์ให้นมเย็นฟัง: ชอบ/งง/กลัวตรงไหน
