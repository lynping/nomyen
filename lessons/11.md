# บทที่ 11: Claude Code ขั้นสูง + Automation 🌳

**เป้าหมาย:** ผู้เรียนรู้จัก CLAUDE.md, Skills, MCP และแนวคิด automation — เห็นภาพว่าจะสร้าง "ผู้ช่วยเฉพาะทาง" ของตัวเองได้ยังไง

## หัวข้อ 11.1 — CLAUDE.md: สมองประจำโฟลเดอร์

- ไฟล์ชื่อ `CLAUDE.md` ในโฟลเดอร์ = คำสั่งถาวรที่ Claude Code อ่านทุกครั้งที่เริ่มงานในโฟลเดอร์นั้น
- เหมือน Custom Instructions (บทที่ 7) แต่ผูกกับโฟลเดอร์งาน — แต่ละโปรเจกต์มีกติกาของตัวเอง
- ใส่อะไรได้บ้าง: เราเป็นใคร, งานนี้คืออะไร, ชอบให้ทำงานแบบไหน, ห้ามทำอะไร, ไฟล์ไหนสำคัญ
- **ตัวอย่างที่ดีที่สุดอยู่ตรงหน้า:** คอร์สนี้ทั้งคอร์สคือ CLAUDE.md ไฟล์เดียว! เปิดให้ผู้เรียนดูได้เลยว่า "นมเย็น" ถูกสร้างยังไง — แล้วบอกว่า "คุณก็สร้างผู้ช่วยแบบนี้ได้เหมือนกัน"

## หัวข้อ 11.2 — Skills: ท่าไม้ตายสำเร็จรูป

- Skill = ชุดคำสั่ง+ความรู้สำเร็จรูปที่สอน Claude ทำงานเฉพาะทาง เช่น ทำไฟล์ Excel, ทำสไลด์, ทำ PDF
- มี skill สำเร็จรูปให้ใช้ และสร้างเองได้ — บทที่ 12 จะสอนลงมือสร้างจริงแบบละเอียด
- ตัวอย่างการใช้: "สร้างใบเสนอราคาเป็น PDF", "ทำสไลด์นำเสนอจากรายงานนี้", "สรุปยอดขายเป็นไฟล์ Excel พร้อมกราฟ"
- แนวคิดสำหรับผู้เรียน: งานประจำที่มีขั้นตอนตายตัว → เหมาะทำเป็น skill

## หัวข้อ 11.3 — MCP: ต่อ AI เข้ากับเครื่องมืออื่น

- MCP (Model Context Protocol) = "ปลั๊ก" มาตรฐานที่ให้ Claude ต่อกับบริการอื่น: Google Drive, ปฏิทิน, อีเมล, Notion, ฐานข้อมูล ฯลฯ
- ต่อแล้วได้อะไร: "ดูปฏิทินพรุ่งนี้แล้วสรุปว่าต้องเตรียมอะไร", "หาไฟล์ใน Drive แล้วสรุป", "อ่านงานใน Notion แล้วจัดลำดับความสำคัญ"
- ไม่ต้องเข้าใจเทคนิคลึก — แค่รู้ว่า "ต่อได้" และการต่อทำผ่านหน้า settings/connectors
- เตือนความปลอดภัย: ต่อเฉพาะบริการที่เชื่อถือได้ และเข้าใจว่าให้สิทธิ์อะไรไป

## หัวข้อ 11.4 — คิดแบบ Automation

- สูตรมองหางานที่ควร automate: ทำซ้ำบ่อย + ขั้นตอนชัด + ใช้เวลานาน = เป้าหมายชั้นดี
- ตัวอย่าง workflow อัตโนมัติที่คนทั่วไปทำได้:
  - เช้าวันจันทร์: "อ่านไฟล์ยอดขายสัปดาห์ก่อน → สรุป → ร่างอีเมลรายงานหัวหน้า"
  - หลังประชุม: "เอาโน้ตดิบ → ทำสรุปประชุม → แยก action items → สร้างไฟล์ติดตามงาน"
  - งานเอกสารซ้ำๆ: "อ่านข้อมูลลูกค้าใหม่ → กรอกลง template ใบเสนอราคา → สร้าง PDF"
- หลักคิดสำคัญ: automation ที่ดีเริ่มจาก workflow ที่เราทำเองจนเชี่ยวก่อน (บทที่ 9) แล้วค่อยส่งมอบให้ AI

## 🏋️ แบบฝึกหัดท้ายบท (ชิ้นส่วนโปรเจกต์ #11 — ใกล้เส้นชัย!)

1. เขียน `CLAUDE.md` ฉบับแรกของตัวเอง สำหรับโฟลเดอร์งานจริง 1 โฟลเดอร์ (นมเย็นช่วยร่าง โดยอิงจาก Custom Instructions บทที่ 7 + workflow บทที่ 9)
2. ทดสอบ: เปิด Claude Code ในโฟลเดอร์นั้น สั่งงาน แล้วดูว่ามันทำตามกติกาใน CLAUDE.md ไหม
3. บันทึกไฟล์ CLAUDE.md ที่เขียนลง `my-project/my-claude-md.md` เก็บเป็นผลงาน

## สรุปท้ายบท

CLAUDE.md = ผู้ช่วยประจำโฟลเดอร์ / Skills = ท่าสำเร็จรูป / MCP = ต่อกับโลกภายนอก / automation เริ่มจาก workflow ที่เราเชี่ยว / บทต่อไป: ลงมือสร้าง Skill ของตัวเองจริงๆ!
